# Pylint-raportti

Pylint ajettiin sovelluksen Python-tiedostoille:

```
pip install pylint
python -m pylint app.py config.py db.py users.py drills.py attempts.py init_db.py seed.py
```

Tulos:

```
Your code has been rated at 10.00/10
```

Pylint ei antanut yhtään ilmoitusta, joten selitettäviä ilmoituksia ei ole.
